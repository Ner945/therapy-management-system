full stack therapy management system I made for my Computer Science course.
The app allows users to manage therapists, clients and therapy sessions.

Technologies used:
JavaScript
HTML
CSS
Node.js
Express
MySQL
Raect

Features:
View therapists
Add, edit and delete therapists
View clients
Add, edit and delete clients
Create and manage therapy sessions
Sessions are linked to both therapists and clients
React frontend connected to a Node and Express backend
MySQL database

How to run:
Install Node.js
Install MySQL
Run the schema.sql file inside the database folder
Create a MySQL user with access to the therapy_system database
use backend/.env.example, fill with new details and rename it to .env

Backend:
Open the backend folder
Run npm install
Run node server.js
The backend runs on http://localhost:5000

Frontend:
Open the frontend folder
Run npm install
Run npm start
The frontend runs on http://localhost:3000

Sample data:
Run database/schema.sql first
Run database/sample-data.sql to add sample therapists, clients and sessions
